# Model Card: OrderGuard AI Risk Predictor

## Model Details
- **Architecture:** Random Forest Classifier
- **Framework:** scikit-learn
- **Version:** 0.1.0
- **Task:** Binary Classification (Predicting RTO - Return to Origin)

## Intended Use
- **Primary Use Case:** Prioritizing COD (Cash on Delivery) orders for manual review by predicting the probability of delivery failure.
- **Out of Scope:** Automating order cancellation or making definitive statements about customer intent.

## Training Data
- **Source:** Synthetic E-commerce Data generated by `generate_synthetic_data.py`.
- **Size:** 5,000 orders (80% training, 20% validation).
- **Class Imbalance:** 17.8% positive class (RTO). Addressed using `class_weight='balanced'`.
- **Chronological Split:** Yes, data was sorted by timestamp before splitting to prevent target leakage.

## Features
- **Numeric:** `order_value`, `items_count`, `address_length`, `name_length`, `past_orders_from_ip`
- **Categorical:** `phone_valid`, `email_valid`

## Evaluation Results
- **Metric:** PR-AUC (Precision-Recall Area Under Curve). Chosen over ROC-AUC due to class imbalance.
- **Performance:** 0.6930 PR-AUC.
- **F1-Score (Positive Class):** 0.75
- **Recall (Positive Class):** 0.78

## Ethical Considerations & Bias
- **Fairness:** The model does not use explicitly protected attributes (like gender or race). However, geographic features (like `address_length` or embedded zip codes if added later) could become proxies for socioeconomic status.
- **Actionability:** The model predictions should always remain a suggestion, leaving the final decision (Approve/Reject) to a human reviewer to avoid systematic bias enforcement.
